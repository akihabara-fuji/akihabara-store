# Sistem Kerja Konten

Satu file HTML mandiri (tanpa build) untuk dipasang di portofolio dikapriyadi.site sebagai menu **Sistem Kerja**.

- Jalur: Affiliate, Analisis Media Sosial, Produksi Video AI, Pengelolaan Website
- Bersama: Kalender, Riset Audiens & Pasar, KPI & Funnel, Eksperimen, Bukti & Portofolio, Impor & Ekspor
- Data tersimpan di localStorage browser pengunjung (tidak ada backend). Backup lewat menu Impor & Ekspor.
- Data awal (akun sosmed, 3 web, log rilis, permintaan) diambil dari riwayat chat Dika per 25 Nov 2026.
- Data demo selalu berlabel "DATA DEMO — BUKAN DATA AKTUAL".

## Pemasangan (belum dilakukan)
Taruh `index.html` di `/var/www/dikapriyadi/sistem-kerja/index.html` lalu tambahkan menu "Sistem Kerja" di portofolio.
Tanya Dika dulu sebelum deploy ke VPS; versi live portofolio (graphite-mono vs versi terang) harus dikonfirmasi dulu.
