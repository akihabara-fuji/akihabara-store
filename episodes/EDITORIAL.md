# Aturan editorial (wajib untuk semua episode)
Prinsip: jangan minta perhatian audiens sebelum memberi alasan untuk memperhatikan.

Struktur: 0-3 dtk HOOK, 3 dtk sampai ±80% VALUE (bukti, demonstrasi, cerita, eksperimen), bagian akhir CTA.

HOOK: muncul maksimal 3 dtk pertama; memancing penasaran, mengangkat masalah, menunjukkan hasil, atau pernyataan kuat dan relevan.
CTA: satu tindakan utama, sesuai tujuan konten (komentar, simpan, bagikan, coba skill, ikuti episode berikutnya). Tidak selalu "follow".
Dilarang: membuka dengan nama, jabatan, logo panjang, atau salam tanpa value; klaim tanpa bukti visual/penjelasan jujur; footage atau capaian karangan.
Satu video = satu pesan utama. Visual berubah mengikuti alur, bukan slideshow.
Validasi: `npm run episode:check` (status READY ditolak bila hook/CTA belum lengkap).
