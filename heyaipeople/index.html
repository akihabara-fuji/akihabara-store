Pertanyaan yang Sering Diajukan

Semua yang perlu kamu tahu sebelum mulai merender video Remotion 2D.

Apakah wajib jago coding React untuk memakai template ini?

Tidak wajib! Setiap template sudah dilengkapi file konfigurasi props.json yang tinggal kamu ganti isi teks, warna, maupun angkanya. Cukup ketik npx remotion render untuk mengekspor MP4 60fps.

Apakah butuh Adobe After Effects atau Premiere Pro?

Sama sekali tidak butuh. Semua animasi 2D dibangun murni di atas web & React menggunakan Remotion, jadi bisa dirender langsung lewat terminal laptop (Windows/Mac/Linux) maupun server cloud.

Bagaimana cara pemesanan dan pengiriman filenya?

Masih manual: pilih template, klik "Pesan via WhatsApp", lalu admin kirim detail pembayaran dan memprosesnya langsung di chat. File .ZIP atau undangan repositori GitHub dikirim admin lewat WhatsApp setelah pembayaran dikonfirmasi.
