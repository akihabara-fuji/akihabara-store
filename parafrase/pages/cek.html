Unggah satu file. Kami membaca judul, bahasa, dan jenisnya sendiri, menandai bagian yang perlu dibenahi, lalu tim kami merevisinya.

Tarik dan lepas file di sini
File Word (.docx) atau PDF. Maksimal 25 MB, tanpa batas jumlah kata.
700 kata pertama dibuka gratis. File PDF dibaca sebagai teks (tanpa tata letak), jadi Word lebih akurat.
File dipilih:
1. UnggahCukup satu file dokumenmu.
2. Cek isiannyaDetail terisi otomatis. Isi nomor WhatsApp saja.
3. Bayar lewat QRISRp40 per kata. Hasil dikirim ke WhatsApp dan halaman Cek Pesanan.

Pratinjau dokumenmu

Sorotan warna menunjukkan bagian yang akan kami kerjakan. Satu paragraf dibuka sebagai contoh: salahnya di mana dan harusnya bagaimana. Catatan lainnya dibuka setelah pembayaran.

Satu paragraf contoh dibuka agar kamu tahu bentuk catatannya. Sisanya tersamar dari server, bukan sekadar efek tampilan, jadi teks aslinya tidak ikut terkirim sebelum pembayaran.
