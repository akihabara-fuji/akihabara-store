Ceritakan kebutuhanmu.

Tulis kebutuhan, lampirkan file soal atau masukan tutor. Bayar lewat QRIS, hasil dikirim admin ke WhatsApp-mu sesuai status pesanan. Masuk dengan akun hanya diminta saat kamu memesan.

Dikerjakan oleh tim admin Catatan Akademik dengan memverifikasi semua aspek aturan bahasa agar lebih enak dibaca, lalu siap dikirim.

Panduan catatan tutor: tempel catatan atau masukan tutor atas tugas sebelumnya (nilai, bagian yang harus diperbaiki, saran). Boleh juga lampirkan foto atau file catatannya lewat tombol di bawah. Tidak ada catatan? Kosongkan saja. Progres akan dikerjakan sesuai template yang berlaku.

Word, PDF, gambar, atau .txt. Maksimal 5 file, 10 MB per file.
Hasil revisi masih belum sesuai catatan tutor? Isi ID pesanan revisi terakhir, tetap gratis. File dari luar? Kosongkan, lalu unggah file lamanya.

Metopen dikerjakan mengikuti standar Telaah Pustaka (Bab 4) dan Kerangka/Model (Bab 5): tematik, mengarah ke research gap, model berbasis teori. Dicek dengan Cek Parafrase dan Audit sebelum dikirim.
Progres ini akan dikerjakan tim admin Catatan Akademik. Jika ada revisi, pilih Revisi Metopen di pilihan atas.
